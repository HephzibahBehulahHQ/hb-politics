# Politics division guidance

This repository represents the HB Politics division. [hb-AI-policy](https://github.com/HephzibahBehulahHQ/hb-AI-policy) governs agent work; [hb-design-system](https://github.com/HephzibahBehulahHQ/hb-design-system) governs visual standards. Read the README and `docs/editorial-guidance.md`.

Keep civic applications, datasets, editorial systems, election feeds, product code and deployments in dedicated product repositories. Preserve approved branding. Use branches and PRs; do not deploy or merge to `main` without authorization.
